## ⚡ Processo em 3 etapas

### Etapa 1: Preparar credenciais (20 min)
- [ ] Supabase (banco de dados) - criar tabela
- [ ] SendGrid ou Gmail (email)
- [ ] Railway ou Vercel (deploy)
- [ ] GitHub (se usar Railway)

### Etapa 2: Deploy (10 min)
- [ ] Push código para GitHub (Railway)
- [ ] Ou deploy direto (Vercel)
- [ ] Aguardar ~5 minutos

### Etapa 3: Configurar variáveis (5 min)
- [ ] Adicionar SUPABASE_URL
- [ ] Adicionar SUPABASE_KEY
- [ ] Adicionar SENDGRID_API_KEY
- [ ] Adicionar ADMIN_EMAIL
- [ ] Redeploy

**Total: ~35 minutos** ✨
